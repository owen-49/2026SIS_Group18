# 网页前端与后端联调需求

> 日期：2026-08-29
>
> 对象：网页前端开发人员

## 目标

让用户能够通过网页上传、查看和管理 PDF 与 BibTeX 文件，并使用后端返回的真实数据。

## 后端当前已支持

- 上传 PDF 和 `.bib` 文件；
- 将上传文件和解析结果保存在本地；
- 返回 PDF 页数、段落数和 Bib entry 数量；
- 返回本地 Library 中的所有 PDF 和 Bib 记录；
- 提供 Bib metadata 验证结果。

## 网页前端需求

1. 上传功能同时支持 PDF 和 `.bib` 文件。
2. Library 同时展示用户上传的 PDF 和 Bib 文件。
3. PDF 显示页数和段落数，Bib 显示 entry 数量。
4. 页面刷新后，已上传的 PDF 和 Bib 仍能从后端加载并显示。
5. 清楚展示文件状态：处理中、完成或失败。
6. 上传或读取失败时，向用户显示后端返回的错误信息。
7. 使用真实后端数据，不将 Mock 数据显示为真实结果。
8. 原有 PDF 上传和展示功能不能受到影响。

## 需要使用的后端接口

- `POST /api/parse`：上传并解析 PDF 或 Bib；
- `GET /api/parse/{paper_id}`：查询文件状态；
- `GET /api/papers`：读取本地 Library；
- `POST /api/verify/bib`：验证 Bib metadata。

## 当前预期情况

真实 PDF Parser 尚未完全接入，因此部分 Bib 验证字段可能返回 `PDF_MISSING`。这表示暂时缺少 PDF metadata，不代表网页或接口发生故障。

本次网页联调范围是 PDF 和 `.bib`。当前后端不接受整个 `.tex` 文件上传；如果后续需要网页上传 `.tex`，应作为单独需求确认。

## 验收标准

- 用户可以从网页成功上传 PDF 和 Bib；
- 上传后的两种文件都出现在 Library；
- Bib 显示正确的 entry 数量；
- 刷新页面后文件记录仍然存在；
- 失败状态和错误信息能够正确显示；
- 原有 PDF 功能正常。
