# User Research

This directory contains interview notes, personas, and synthesized findings
from user research conducted W1-W3.

---

## Research Plan

- **Target**: 5 PhD students / researchers who recently submitted to top CS conferences
- **Method**: 30-min semi-structured interviews
- **Timeline**: W1-W2 interviews, W3 synthesis

## Interview Guide

See preparation plan for full interview script.

## Output Files

- `interviews/` — Raw interview notes (one per participant)
- `personas.md` — Synthesized user personas
- `user-stories.md` — Top 5-10 user stories
- `findings.md` — Key findings and design implications
